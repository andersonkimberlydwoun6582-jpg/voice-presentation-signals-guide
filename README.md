# Voice Presentation Signals Guide

An original, plain-language guide to the signals people often discuss when they talk about vocal presentation: pitch, pitch movement, brightness, and recording privacy.

For an interactive private browser check, see [Voice Gender Test](https://voicegendertest.com/).

## Contents

- `article.md` — the full educational article.
- `quick-reference.md` — a compact reference sheet for learners and teachers.
- `LICENSE` — MIT License.

## Intended use

This material is for education and self-reflection. It should not be used to diagnose a person, decide their identity, or make employment, medical, or legal judgments.
